# 小鹤双拼五笔形 FLYPY_YK 方案

## 说明

- 本项目是基于小鹤双拼输入法的 Rime 方案，将小鹤双拼的形码转换为五笔形码，以便五笔用户更轻松地使用小鹤双拼输入法，达到与鹤形输入相同的输入效率。
- 小鹤双拼默认使用鹤形补码来解决同音字的重码问题。但对于五笔用户来说，学习鹤形反而可能会产生混淆。因此，本方案使用五笔补码来解决重码问题，无需额外学习鹤形码。

## 输入方案

本方案默认为单字方案，单字全码为 4 码，前两码为小鹤双拼码，后两码为五笔码。

例如：

- `衡`：小鹤双拼为 `hk`，五笔全码为 `tqdh`，本方案编码为 `hktq`
- `框`：小鹤双拼为 `kl`，五笔全码为 `sagg`，本方案编码为 `klsa`

五笔的一级简码不会作为补码，例如：

- `我`：小鹤双拼为 `wo`，五笔一级简码为 `q`，五笔全码为 `trnt`，本方案编码为 `wotr`（而不是 `woq`）
- `这`：小鹤双拼为 `ve`，五笔一级简码为 `p`，五笔全码为 `ypi`，本方案编码为 `veyp`（而不是 `vep`）

## 快速安装与部署

本项目已将所有配置文件统一部署至 `deploy/` 目录。只需将 `deploy/` 目录下的所有文件复制到您对应平台的 Rime 用户配置目录下即可。

### 1. 复制配置文件

- **Windows (小狼毫 Weasel)**:
  复制 `deploy/` 内的所有文件至 `%APPDATA%\Rime`（快捷键 `Win + R` 输入 `%APPDATA%\Rime` 打开）。
- **macOS (鼠须管 Squirrel)**:
  复制 `deploy/` 内的所有文件至 `~/Library/Rime`。
- **Linux (Fcitx5-Rime)**:
  复制 `deploy/` 内的所有文件至 `~/.local/share/fcitx5/rime`。

### 2. 重新部署

复制完成后，在输入法菜单中点击 **“重新部署”**（Re-deploy）即可完成方案的生效。

## 包含的方案说明

1. **`flypy_yk`（小鹤双拼 + 五笔形码主方案）**
   主推单字四码确定性输入方案。
   - **快捷选字**：支持 `;`（分号）直接选择第 2 候选，`/`（斜杠）直接选择第 3 候选。
   - **通配符支持**：在形码位置输入 `?` 可对模糊的五笔形码进行通配匹配。
   - **Lua 模块化扩展 (`deploy/lua/`)**：
     - `V123`: 金额大写转换 (大写 V 触发)
     - `C100*1.13`: 简易算式计算器 (大写 C 触发，包含乘方 `^` / 取模 `%` 与精度格式化)
     - `date` / `time` / `dt` / `iso`: 动态系统日期时间与 ISO 8601 标准时间戳
     - `help`: 快捷指令提示卡片
     - 五笔编码/拆字提示滤镜
2. **`wubi86` / `wubi_flypy`（五笔及双拼混输方案）**
   提供原生五笔 86 输入，并支持按 `z` 键反查小鹤双拼编码。

## 词库维护与扩展构建工具

项目根目录下提供 `custom.py` 脚本，用于从基础双拼与五笔词库离线编译/生成加形词库 `flypy_yk.wubi.dict.yaml`。

```bash
# 构建并更新 deploy/flypy_yk.wubi.dict.yaml
python3 custom.py --build

# 检查当前编码重码情况
python3 custom.py --check-duplicates
```
